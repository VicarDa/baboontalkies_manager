# 查看日志指南

## Cloud Run revision

```bat
gcloud run revisions list --service baboontalkies-manager --region asia-east1 --project project-59ee4a6b-1c4d-4d7b-a37
```

## 最近日志

```bat
gcloud logging read "resource.type=cloud_run_revision AND resource.labels.service_name=baboontalkies-manager" --project project-59ee4a6b-1c4d-4d7b-a37 --limit 100 --order desc
```

## 健康检查

```bat
curl https://baboontalkies.pandada.world/health
curl https://baboontalkies.pandada.world/api/last-refresh-time
```
