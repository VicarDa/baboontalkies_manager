# 本地抓取服务使用说明

## 本地启动

Windows 下使用 cmd：

```bat
cmd /c npm install
cmd /c npm run scraper
```

Dashboard 本地服务：

```bat
cmd /c npm run dashboard-dev
```

## 正式服务联调

正式 manager 入口：`https://baboontalkies.pandada.world`

```bash
curl -s https://baboontalkies.pandada.world/health
curl -X POST https://baboontalkies.pandada.world/api/trigger-remote-scrape
curl -s https://baboontalkies.pandada.world/api/last-refresh-time
```

正式环境问题通过 Cloud Run revision 状态和 Cloud Logging 排查。
