🗂️ 教材管理

一个教材可以包含多个 PDF。上传后原始 PDF、封面图、逐页内容索引、正文 Markdown、关键内容 JSON 和 `parse.json` 都会落到 OSS 的 `BaboonStudy/Material/<教材名>/` 目录下；解析与关键内容提炼都走后台任务，不阻塞上传流程。

创建教材

创建教材时可一次上传多个 PDF。教材名将作为 OSS 文件夹名，所以名称必须唯一。

可一次选择多个 PDF；上传后会按教材内 PDF 子项保存并自动排队解析。

关键内容提炼提示词模板

统一管理豆包提炼逐页关键内容的提示词。请保留 {{material_title}}、{{pdf_name}} 和 {{page_source}} 占位符。

当前模板会在 PDF 解析完成后用于豆包 2.0 Pro 的逐页关键内容提炼，并把 PDF 级的 main / main_start / main_end / title / words_count 与每页的 title / page / seg / words 结果写入数据库和 OSS。

关键词解释提示词模板

统一管理豆包的关键词解释提示词。请保留 {{keywords}} 占位符，系统会自动注入当前 PDF 尚未入词库的关键词。

当前模板会在 PDF 关键内容提炼完成后批量请求豆包，返回的词性与词义会写入 bt_material_keywords 词库表，并用于页面上的关键词解析统计。

教材组模板范围

缩略图、视频和位置标定模板按教材组生效。请选择要编辑的教材组，不同教材组可使用不同提示词。

未分组教材继续使用默认模板；已分组教材会优先使用这里保存到对应教材组的模板。

缩略图提示词模板

这里管理当前教材组的缩略图提示词模板。请保留 {{title}} 和 {{body}}；可选使用 {{material_group}}、{{material_name}}、{{keywods}}。

当前模板会在制作页中作为当前教材组的基础缩略图模板使用，提交时会按语言自动追加“生成对应语言图片”的前缀，并替换 {{title}}、{{body}}、{{material_group}}、{{material_name}} 与 {{keywods}}。

视频提示词模板

这里管理当前教材组的“生成视频”默认提示词。请保留 {{title}} 和 {{body}}；可选使用 {{material_group}}、{{material_name}}、{{keywods}}。

当前模板会在制作页中作为当前教材组的视频模板使用，并替换 {{title}}、{{body}}、{{material_group}}、{{material_name}} 与 {{keywods}}。

配套图提示词模板

这里管理当前教材组的“生成配套图”默认提示词。语言模板请保留 {{language}} 占位符。

在制作工作台里，你可以基于这三个教材组模板临时改写本次请求用的 prompt，也可以直接从弹窗里保存回当前教材组。

位置标定提示词模板

统一管理当前教材组的“位置标定”提示词。请保留 {{title}}，并保留 {{segments}} 或 {{body}} 占位符。

在制作工作台里，你可以基于这个教材组模板临时改写本次标定请求用的 prompt。

教材组

教材组仅用于归档与教材级排序。删除分组前需先移走分组下的教材。

1. 生成缩略图

可一次批量生成多种语言缩略图。配套图与删除功能在缩略图 hover 时可用。

正文会按所选范围从对应页的 segN_text 拼接：同页内单换行，跨页双换行。这里默认是本次制作的临时覆盖；如需长期生效，可直接点击“保存为教材组模板”。

2. 生成视频

选择来源缩略图后调用 Atlas OpenAPI 生成视频。默认优先选择“无文字”配套图，首帧和尾帧都会使用同一张图。

视频 prompt 会沿用当前制作范围下的 {{body}} 规则，并在浏览器控制台打印完整最终提示词。

3. 标定位置

选择已生成的英文或中文缩略图，调用 Doubao 2.0 Pro 标定标题与各段对应的文字框、图片框。

这里默认是本次标定的临时覆盖；如需长期生效，可直接点击“保存为教材组模板”。

4. 生成语音

按页内的 segN_text 逐段生成 MP3。同一页如果有多个 seg，会生成多段音频。

每个 segN_text 会单独生成一段音频。

5. 生成局部视频

稍后实现，当前仅保留制作区块。

局部视频生成逻辑将在后续接入。
